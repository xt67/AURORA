# AURORA v2 publication execution addendum

19 November 2026. The researcher requested: "perform remaining experiments i need the research part completed 100%". This authorizes execution of the previously proposed four-condition comparison. This addendum records implementation choices before the first publication fit or test evaluation. It does not replace or edit historical protocols or attest to clinical review.

## Frozen design

The dataset, split, budgets, seeds, model settings and hypotheses are those in `configs/study_simplified_proposal.yaml` and `docs/EXPERIMENT_PROTOCOL_SIMPLIFIED.md`: 590 retained images; 413/89/88 train/validation/test; nested TB training budgets 52/105/210; all 203 normal training images; seeds 42/123/999. A uses real images; B adds one repeated TB image per selected TB source, sampled with replacement; C transforms TB images only; D adds the same count of DCGAN images as B. Normal images in C are never augmented. No horizontal flips occur.

The nine GANs use 200 fixed epochs, batch size 16, no dropped remainder batch, full precision and the existing BCE DCGAN. Existing trainer details include real-target smoothing 0.9, gradient clipping 1.0 and arithmetic means of batch losses. Keep the final epoch; do not select generators using diagnostic or holdout scores. The trainer receives only hash-verified selected real TB tensors and no image paths or evaluation loader. Each run produces exactly 52, 105 or 210 synthetic images with a recorded seed, saved as 8-bit PNGs without sample rejection.

All 36 ImageNet-pretrained ResNet-18 classifiers receive 1000 Adam updates, batch size 16, uniform replacement sampling, learning rate 0.0001, weight decay 0.0001, unweighted cross entropy and CUDA AMP. Each condition resets the model and random seeds. Select minimum validation cross entropy every 100 updates, breaking equal losses by the first checkpoint. Select maximum validation F1, breaking ties by the highest threshold. Persist validation probabilities, threshold and checkpoint hashes before test evaluation. Fit the entire grid before evaluating any test images; no test-driven revisions, reruns or selections.

Deterministic preprocessing uses grayscale, bilinear square resizing to 128 pixels, repeated three channels and ImageNet normalization. C applies random affine rotation ±5 degrees and translation ±5% after resizing (nearest-neighbour interpolation, zero fill), then brightness/contrast jitter 0.1, then normalization. These are experimental transformations, not clinically validated manipulations. The original and historical artifacts stay read-only. Hash verification and decoding use the same bytes; the cache is a runtime optimization, not a data change.

## Diagnostics and analysis fixed before execution

Secondary generator diagnostics use the selected real TB training images only as the reference: 64×64 grayscale pixel RMSE nearest neighbours, pairwise synthetic diversity and exact duplicate image counts. Record every synthetic image and its nearest training neighbour. These are exploratory collapse/memorization screens and cannot establish privacy or diagnostic validity. No FID/KID is claimed: the earlier protocol made these optional, and the primary diagnostic plan here uses no additional learned feature model or validation/test reference. Show unfiltered fixed-order samples; do not curate attractive outputs.

Primary outcome is TB recall. Supporting outcomes: AUPRC, F1, specificity, AUROC, confusion matrix, Brier score and ten-bin expected calibration error. Report every seed and budget, mean and sample standard deviation, and paired D−A and D−B differences. Use 1000 stratified image-group bootstrap replicates per fitted model; the groups are image identities, not patients. Three-seed bootstrap contrasts are descriptive and unstable. Cohort tables retain their small denominators (Montgomery test has 19 images and eight TB-labelled images). No universal superiority, significance, causal or clinical claim follows automatically.

The separate publication gate binds the historical proposal and all its inputs, this config/addendum, selected training IDs for each budget, ImageNet weight hash, code hash and commit. Feasibility approval and historical v1 approval cannot authorize this path. The user's actual instruction is recorded as the authorization basis; no supervisor, human duplicate review, ethics approval or signature is invented.

Failures preserve artifacts and halt the grid. Resume only skips completed, hash-checked fits under identical bindings; interrupted fits are never overwritten or silently restarted. Full experimental completion means all 36 measured classifiers and nine measured GANs plus analysis, not guaranteed publication acceptance. Author declarations, external review and venue submission remain separate.
